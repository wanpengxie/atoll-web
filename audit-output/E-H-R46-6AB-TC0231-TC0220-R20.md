## 2. TC0231 warm-cache plan contract

### User action and strict observables

The baseline is
[`f7-history-warm-cache-baseline-0231.spec.js:44`](/home/xiewanpeng/.atoll/device/daemons/local-device/channels/c0.dev/atoll-web/tests/browser/f7-history-warm-cache-baseline-0231.spec.js:44):
reset `huge-history`, log in through the real app, wait for the durable current
schema, reload, then perform two native top gestures. The acceptance order is
strict:

1. Read the IndexedDB `rows` object store and count only physical records whose
   `channelId` is `c0`; require `128 ≤ count < 1000`.
2. Do not accept `meta.value.rowCount`, a transport receipt, a rendered-row
   count, or the deleted `atoll-feed-v8` store as a warm-cache substitute.
3. Once the bound is met, require the startup completion ledger to be settled;
   every physical page has one public completion identity and no unowned
   in-flight page remains.
4. Reload, issue one native top gesture, require exactly one
   `history.intent_started` and one `history.intent_satisfied`; repeat once and
   require exactly one new demand with `anchorSeq` strictly smaller than the
   first.

The first failing boundary terminates the case. Later gesture evidence cannot
close a failed durable warm-set requirement.

page instead of collecting enough real pages to reach the 128-row bound. This
is a regression packet, not a cache-quota or fixture excuse.

"history.segment_requested", ...)` publisher; the direct probe therefore sees
zero such events. The old test counter was an obsolete scheduler
implementation oracle, and the current red result never reached that assertion
because the physical-row threshold failed first. This round replaces that
counter at [`f7-history-warm-cache-baseline-0231.spec.js:61`](/home/xiewanpeng/.atoll/device/daemons/local-device/channels/c0.dev/atoll-web/tests/browser/f7-history-warm-cache-baseline-0231.spec.js:61)

matching `history.batch_complete` ref. The strict physical-row bound remains
unchanged, and no missing event is interpreted as permission to relax it.
