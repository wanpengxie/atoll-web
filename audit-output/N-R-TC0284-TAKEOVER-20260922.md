## User contract and owner

conversation roots from tool lifecycle, timer/control, and non-readable
activity. Nested tool frames, timer control, and activity remain quiet. A
standalone `readable_event` materializes as a public presentation row and
physical reading observation. A top-level request and terminal are readable
root revisions; a readable timer terminal is independently visible and
notifiable. A visible row is acknowledged only through the mounted viewport.

classification and root identity, WorkspaceLayout for the rail, and the
Reading/presentation adapter for physical visibility. This migration adds no
cursor, store, diagnostic oracle, compatibility path, fixture, or product
