# F6 性能与预览资源预算

状态：已实现并由自动化测试守门

## 可复现预算

| 场景 | 固定预算 | 证明方式 |
|---|---:|---|
| 动态与任务长列表 | 每个视图最多挂载 120 个业务行 | `tests/f6-performance.test.jsx` DOM 断言 |
| 当前频道文件目录 | 必须由服务端分页或 120 行 UI 窗口形成硬边界 | 频道文件主线测试（不得用旧产物库语义证明） |
| 本地待提交状态 | 最多挂载最近 50 行 | `Timeline` DOM 边界 |
| 展开的系统诊断 | 最多挂载最近 120 行 | `Narration` DOM 边界 |
| 一万项窗口投影 | jsdom 下低于 50ms | 确定性性能测试 |
| 五千条动态首屏 | jsdom 下低于 2000ms，业务 DOM 仍为 120 行 | 确定性性能测试 |
| 文本预览 | 512 KiB | 流式读取，超限立即取消 |
| 图片预览 | 20 MiB | 声明大小、Content-Length、Blob 三重检查 |
| PDF 预览 | 25 MiB | 同上 |
| 音视频预览 | 50 MiB | 同上 |

运行命令：

```bash
npx vitest run tests/f6-performance.test.jsx
```

## 行为约束

- 长列表采用固定窗口翻页，完整账本和索引事实不被截断；只限制当前 DOM 投影。
- 文件列表预算只约束当前频道默认挂载目录的 UI 投影，不把引用/派生产物解释成跨频道全局产物库。
- 动态仅在用户停留于最新页且滚动位置接近底部时跟随新 feed；阅读历史时不会被拉走。
- 切换频道恢复最新窗口，筛选条件改变后回到筛选结果最新页。
- 预览关闭或切换对象时通过 `AbortController` 取消数据请求。
- Object URL 在正常切换、卸载，以及异步 Blob 晚于卸载到达三种路径下都会释放。
- 不支持或超限预览只降级站内展示，不改变下载与来源事实。
