# 阅读视口执行模型

状态：执行层重构与受控验证完成；用户反馈“好了一些，但是还没有完全解决”，真实场景仍未验收（2026-09-16）。本次是阶段性修复，不是滚动问题关闭。替代旧规格中以 `firstItemIndex + layoutEffect` 证明原子性的错误判断。

## 故障边界

旧 Adapter 同时开启 Virtuoso 的 prepend、测高补偿、尾随和可重试的索引导航，
再执行自己的 DOM 锚点修正。产品进入 browsing 不会取消库里已经排队的动作。
函数形式的 followOutput 也无法关闭库中只检查 `!== false` 的尺寸变化分支。
恢复命令混用了全局虚拟索引与数组下标。统一模拟行高的测试未覆盖这些执行路径。

## 唯一执行者

消息时间线改用自己持有测量表的有界窗口。移除该路径对 Virtuoso 的依赖；
本轮不改依赖清单。ConversationViewport 只持有阅读意图、历史需求和消息 ID，
Adapter 独占测量、窗口、物理位置。不存在第二个自动跟随或异步定位执行者。

每次 React 提交之前，从上一版已提交的布局和**此刻**原生 scrollTop 取得阅读锚点。
不能使用历史请求发出时的锚点，也不能用上一次 scroll 事件的位置替代当前位置。
提交后测量本次已物化的消息，更新窗口两端占位，绘制前只提交一次目标位置：

- browsing：`新布局中锚点的位置 - 用户当前锚点偏移`；
- following：新布局的尾部；
- 显式导航：消息 ID 和条内偏移/对齐方式。

测量引起的窗口准备可以有多个同步布局阶段，但准备阶段不写滚动位置；
完成后才提交位置。后续 ResizeObserver 交付是新的尺寸事务，不重放旧导航。
屏幕上方的尺寸变化被抵消，屏幕下方的增长不移动阅读位置。
尺寸测量使用 border box，ResizeObserver 也必须监听 border box，防止 padding/border
变化未触发测量；这项由隔离浏览器中的 padding 增高场景验证。

未物化区域的尺寸估计只用于滚动条与选择候选窗口；进入窗口的 row 必须在
本次绘制前实测。新历史、缓存恢复、live 更新一律走相同布局提交路径。
DOM 只保留视口附近内容；不恢复整表 DOM，不在快速滚动时一次挂载六屏富文本。

## 用户接管和导航

导航只接受 rowID，不暴露数十亿虚拟索引。命令属于当前挂载实例和输入 epoch。
wheel、touch、键盘滚动、滚动条拖动立即推进 epoch，取消尚未执行的导航。
不存在 setTimeout/rAF 中重新执行定位的闭包。scroll 观测本身不发导航命令。

频道阅读会话保存语义锚点；尺寸缓存仅作加速，按 rowID 和实际宽度保存，
不保存一个能覆盖用户阅读意图的物理 scrollTop。旧 Virtuoso 快照不再使用。

Composer、等待区、移动频道目录、固定 32px 阅读间距和数据同步协议保持现有边界。

## 集中验收

实现完整后统一执行：

- 随机异构高度、prepend、append、resize、用户滚动的性质测试；
- 实际 Adapter 的 DOM 生命周期测试（可控异构尺寸和 ResizeObserver），
  覆盖等待历史期间继续滚动、用户取消导航、晚到测量、切频道；
- 既有导航、历史需求、消息呈现测试和生产构建。
- `node tests/browser/reading-viewport-check.mjs`：随机本地端口的独立页面，合成
  自然换行长文本；1100px/390px 两种宽度，逐帧检查 prepend/live 不移位，
  再验证异步 border-box 测量、取消导航和有界 DOM。不使用当前账号或后端服务。

测试不能把函数调用次数当作视觉稳定，也不能将 jsdom 验证写成真实设备验收。

### 验证结果（2026-09-16）

- 全量 114 个测试文件、657 项测试通过；生产构建通过。
- 几何性质测试覆盖 600 个随机参数组合，不将其宣称为完整状态机随机轨迹。
- 8 项实际 Adapter 生命周期测试覆盖异构高度、当前阅读锚点、导航取消和窗口回收。
- 隔离 Chromium 页面在 1100px 与 390px 宽度均通过：每种宽度交替进行 12 次
  prepend/live 更新，采样提交当帧及后续 4 帧，锚点偏差不超过 1px；
  border-box 异步变化、导航取消、按 ID 定位、尾随和 DOM 数量上界检查通过。
- 测试不连接当前频道或后端，不代表 Android 真机、所有输入法及所有富文本组合均已验收。
- 浏览器用合成文本、主动设置滚动偏移和合成 wheel 意图检查布局，不等价于系统触控板/手机惯性滚动，也未覆盖整条真实数据合流链。剩余现象须区分导航抢位、消息内部重排和原生手势交互，不能因上述测试通过就宣称问题关闭。
- 完整增量投影、持久阅读会话和数据同步后置项不属于本次完成范围。
